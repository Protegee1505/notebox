# ADR-0000: Template

- **Status:** proposed | accepted | rejected | superseded
- **Date:** YYYY-MM-DD
- **Spike:** S1..S5 or phase
- **Owner:** role

## Question

What assumption is being tested, and what would make it fail?

## Context

Constraints, environment and versions that affect the result.

## Decision

What was chosen, in one or two sentences.

## Evidence

Commands run, measurements, links to CI runs or artifacts. Numbers, not
impressions. Include the fallback's result when it was tried.

## Consequences

What changes in PLAN.md, what becomes blocked, and what the next agent must
know. If the result contradicts PLAN.md, say so explicitly and stop.
